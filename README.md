# Moon Library Plugin

This is the public plugin package for the Moon workspace library.

## Files

- `plugin.json` contains the plugin metadata and capabilities.
- `src/host.ts` defines the host contract Moon exposes to the plugin.
- `src/Library.tsx` is the UI that renders the library.
- `convex/files.ts` contains the backend contract used by the Convex app.

## Install

This repo is designed to be downloaded from GitHub by the Moon app installer.
