# Moon Creative Studio Plugin

This package contains the `creative-studio` plugin manifest and runtime entry.
Publish this directory as its own GitHub repository, then use that repository
URL in the Moon plugin marketplace record with the slug `creative-studio`.

The complete extraction checklist is tracked in the Moon repository at
`CREATIVE_STUDIO_FILE_MAP.md`. The current entry still resolves the dashboard
and editor from Moon while the files are being moved; do not remove those host
files until that checklist is complete.
